# Decisions

- 2026-11-25: Free distribution route. Android sideload APK, iPhone/iPad via PWA, native iOS optional/paid.
- 2026-11-25: Repository is public (owner choice, for unlimited free Actions minutes). Never commit keys, keystores, or tokens. License changed to all rights reserved on 2026-11-25.
- 2026-11-25: TypeScript 6.0.3 pinned; Vitest 5.1.1; Phaser 4.2.1; Vite 8.3.8; Capacitor 8.6.2.
- 2026-11-25: Added `@types/node@24` (dev) so `tsconfig` can type Playwright config, tests, and tools. `tsconfig` `types` is `["vite/client", "node"]` and `include` also lists the three config files (small deviation from spec 13.1; spec updated to match). Size: types only, no runtime cost.
- 2026-11-25: ESLint uses `typescript-eslint` `strictTypeChecked`; `src/core/**` additionally bans `Math.random/sin/cos/pow`, wall-clock reads, and DOM globals.
- 2026-11-25: CI is `.github/workflows/ci.yml` only; `release.yml` (Android APK, PWA deploy) is Pass 7.
- 2026-11-25: Early APK pipeline test (a slice of Pass 7B) before Pass 1A, approved by the owner, to prove a phone-only owner can receive builds. Adds `capacitor.config.ts` and the generated `android/` project (Capacitor 8.6.2 template: compileSdk/targetSdk 36, minSdk 24, AGP 8.13.0, Gradle 8.14.3, JDK 21). `android/app/build.gradle` reads version from `-PcdVersionName/-PcdVersionCode` and signing from `CD_*` environment variables; the manifest locks `sensorLandscape`.
- 2026-11-25: Release signing key: RSA 4096 PKCS12, alias `cosmicdrift`, certificate SHA-256 `94:1F:C2:...:61:73:84` (full value in docs/RELEASE.md). Generated outside the repo and handed to the owner for offline backup; CI reads it from repository secrets and refuses any other certificate. The agent sandbox's proxy blocks the secrets API, so the owner adds the two secrets by hand.
- 2026-11-25: Vite `base: './'` so one build works in the Android WebView and under a web sub-path.
- 2026-11-25: CI builds a debug APK on every push to `main` (public repo, Actions minutes are free). Release APKs only from `v*` tags via `release.yml`.
- 2026-11-25: GitHub Pages preview deferred: the proxy blocks enabling Pages, and the final PWA origin must be chosen deliberately at Pass 7A because origin = save storage (all `*.github.io` sites of one account share an origin).
- 2026-11-25: Asset manifest file entries gain optional `width`/`height` (pixel size) so O3 can check dimensions at load; spec Appendix A updated.
- 2026-11-25: Vite `build.assetsDir: 'app'` so `dist/assets/` holds only game assets and the manifest (cleaner caching rules for the PWA later).
- 2026-11-25: Scenes get a `GameServices` object through their constructors (asset registry, capabilities, warn) instead of globals or Phaser's data registry.
- 2026-11-25: The performance badge lives in `src/app/` and shows in dev builds or with `?debug=1`, so it also works in staging and phone builds (spec 21.1 "performance overlay available").
- 2026-11-25: `?test=1` exposes a read-only `window.__CD_TEST__` (asset snapshot, capabilities) for browser tests.
- 2026-11-25: Added `tsx` (dev) to run TypeScript tools that import `src/core` (`tools/replay-run`, `tools/perf-bench`). Alternatives: Node type stripping (needs `.ts` import extensions everywhere), `vite-node` (less common). Dev only, no runtime cost.
- 2026-11-25: `Ids.ts` is hand-written for now (planets, difficulties) with a test that checks it against spec Appendix B, instead of a generator; a generator comes when the ID lists grow.
- 2026-11-25: The simulation quantizes inputs at its boundary to the network encoding (axes ×127 as i8, 6 button bits, aim ±3142 mrad), so local play, replays, and online matches see identical numbers.
- 2026-11-25: `CONFIG_HASH` is computed at module load (same value the build-time version in spec 21.2 would produce); `BuildInfo.ts` arrives with Pass 7.
- 2026-11-25: Pass 1B uses a flat test floor (`setup.floorY`) so movement can be tested before tile collision (Pass 1C replaces it). World coordinates stay non-negative, as the snapshot packet requires.
- 2026-11-25: Fixed `.dependency-cruiser.cjs`: `exclude` no longer drops node_modules (it hid package imports from all rules); added `core-no-packages`; added a canary test.
- 2026-11-25: Owner switched the build to auto mode: milestones run back to back (each one fully green locally and in CI, documented, and pushed before the next starts). The agent stops only for device checks, owner-only decisions, or stop-the-line rules. AGENTS.md and spec 22.2 updated.
- 2026-11-25 (Pass 1C): Gravity is "rising" (2600) while moving up and "falling" (4160) otherwise; releasing Jump early only applies the one-time jump cut. The spec's tap-jump figure (77 u, clears one tile) requires this; the old "or jump released" wording gave 61 u, which fails "taps clear one tile". Spec 4.1 updated.
- 2026-11-25 (Pass 1C): The jetpack engages when Jump is held in the air after coyote time with fuel left and the player is no longer rising (vy >= 0), then stays on while Jump is held. This is the rule the spec's derived-reach table was computed with (all ten jetpack numbers reproduce within 0.5 u). Consequence: holding Jump through a full jump hovers at the apex.
- 2026-11-25 (Pass 1C): Wall-jump vy scales with sqrt(planet gravity), like the jump, so shafts work the same on every planet (unscaled, a Kepler wall jump would be 318 u high versus 201 u for a jump). Wall-jump contact counts within 6 u of a wall (`wallJump.contactProbeU`, baseline tuning); wall slide needs contact (1 u).
- 2026-11-25 (Pass 1C): The dash is 10 ticks at 1100 u/s = 183 u (the spec's 176 u was the continuous-time figure for 160 ms). Spec text updated.
- 2026-11-25 (Pass 1C): Static level geometry lives in an immutable `Level` held by `WorldSimulation`, not in `WorldState`, so snapshots stay small. `WorldSetup` names the level (`levelId`, `levelHash`); replay format v2 carries both and refuses a changed level.
- 2026-11-25 (Pass 1C): Level objects: bottom-anchored objects stand on the bottom edge of their tile cell, centered. Moving platforms gain optional `w`/`h` (default 3 × 0.5 tiles), ping-pong along their path, and wait only at the ends. Speed is capped at 600 u/s. Spec 5.2 and Appendix A updated.
- 2026-11-25 (Pass 1C): The parser rejects crumbling (`x`) and cracked (`c`) tiles, non-empty `decor`/`triggers`, and object types whose behavior is not built yet, so no level can silently depend on a missing mechanic. `levels:lint` now runs the game's own parser (LevelLint stage 1); reachability arrives in Pass 2F. Dev levels live in `content/levels/dev/`.
- 2026-11-25 (Pass 1C): Hazard respawn picks the newest safe-ground sample that is at least 1 s old and not blocked right now, then the older sample, then the level spawn. Death (HP 0) restores at the level spawn until checkpoints arrive in Pass 1E.
- 2026-11-25 (Pass 1C): Collision moves pass NaN/Infinity straight through (so the N11 assertion reports them) and cap any single move at 64 sub-steps (2048 u), so a corrupt value can never hang a tick. The finite-number assertion now builds the path only after a hit (about 4x faster).
- 2026-11-26 (Pass 1D): Phaser's own input plugins are disabled (`input: { keyboard: false, mouse: false, touch: false, gamepad: false }`). All input goes through `src/input`: Touch Events on the canvas (non-passive), window key events, canvas mouse events, and Gamepad API polling once per frame, merged by `InputRouter` into one latched `InputFrame` per tick.
- 2026-11-26 (Pass 1D): `touchcancel` releases only the fingers in `changedTouches` (spec 14.2, the more specific rule); `pointercancel`, blur, hidden visibility, page hide, orientation change, pause, panel open, and scene change release everything (M6).
- 2026-11-26 (Pass 1D): After a release-all, gamepad buttons that are still physically held are ignored until released, and OS key repeat is ignored, so refocusing the window never fires a press nobody made.
- 2026-11-26 (Pass 1D): Aim angles are world space with +y down (clockwise from +x), in milliradians; the right stick and the mouse use the same convention.
- 2026-11-26 (Pass 1D): Touch controls are a DOM layer with `pointer-events: none` over the canvas (every touch still lands on the canvas). Overlapping hit areas go to the nearest center; the Classic layout has no overlaps at baseline sizes (tested at 640×360).
- 2026-11-26 (Pass 1D): Modified keys (Ctrl, Cmd, Alt) are never handled, so browser shortcuts keep working (spec 8.13).
- 2026-11-26 (Pass 1D, reopens 1A): The stage is sized to the body's content box (window minus the safe-area padding) instead of the whole window, so on notched iPhones the canvas and touch controls stay inside the safe area.
- 2026-11-26 (Pass 1D): The boot flow goes straight to `LevelScene` (the test arena) until the title screen arrives in Pass 2A; the placeholder `HoldingScene` is gone. A minimal pause (Esc, P, Start, or the touch pause button; also on blur) freezes the loop and resets it on resume; the pause menu arrives with Pass 1E/2A.
