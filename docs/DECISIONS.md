- 2026-11-25 (Pass 1C): Gravity is "rising" (2600) while moving up and "falling" (4160) otherwise; releasing Jump early only applies the one-time jump cut. The spec's tap-jump figure (77 u, clears one tile) requires this; the old "or jump released" wording gave 61 u, which fails "taps clear one tile". Spec 4.1 updated.
- 2026-11-25 (Pass 1C): The jetpack engages when Jump is held in the air after coyote time with fuel left and the player is no longer rising (vy >= 0), then stays on while Jump is held. This is the rule the spec's derived-reach table was computed with (all ten jetpack numbers reproduce within 0.5 u). Consequence: holding Jump through a full jump hovers at the apex.
- 2026-11-25 (Pass 1C): Wall-jump vy scales with sqrt(planet gravity), like the jump, so shafts work the same on every planet (unscaled, a Kepler wall jump would be 318 u high versus 201 u for a jump). Wall-jump contact counts within 6 u of a wall (`wallJump.contactProbeU`, baseline tuning); wall slide needs contact (1 u).
- 2026-11-25 (Pass 1C): The dash is 10 ticks at 1100 u/s = 183 u (the spec's 176 u was the continuous-time figure for 160 ms). Spec text updated.
- 2026-11-25 (Pass 1C): Static level geometry lives in an immutable `Level` held by `WorldSimulation`, not in `WorldState`, so snapshots stay small. `WorldSetup` names the level (`levelId`, `levelHash`); replay format v2 carries both and refuses a changed level.
- 2026-11-25 (Pass 1C): Level objects: bottom-anchored objects stand on the bottom edge of their tile cell, centered. Moving platforms gain optional `w`/`h` (default 3 × 0.5 tiles), ping-pong along their path, and wait only at the ends. Speed is capped at 600 u/s. Spec 5.2 and Appendix A updated.
- 2026-11-25 (Pass 1C): The parser rejects crumbling (`x`) and cracked (`c`) tiles, non-empty `decor`/`triggers`, and object types whose behavior is not built yet, so no level can silently depend on a missing mechanic. `levels:lint` now runs the game's own parser (LevelLint stage 1); reachability arrives in Pass 2F. Dev levels live in `content/levels/dev/`.
- 2026-11-25 (Pass 1C): Hazard respawn picks the newest safe-ground sample that is at least 1 s old and not blocked right now, then the older sample, then the level spawn. Death (HP 0) restores at the level spawn until checkpoints arrive in Pass 1E.
- 2026-11-25 (Pass 1C): Collision moves pass NaN/Infinity straight through (so the N11 assertion reports them) and cap any single move at 64 sub-steps (2048 u), so a corrupt value can never hang a tick. The finite-number assertion now builds the path only after a hit (about 4x faster).
- 2026-11-26 (Pass 1D): Phaser's own input plugins are disabled (`input: { keyboard: false, mouse: false, touch: false, gamepad: false }`). - 2026-11-26 (Pass 1D): After a release-all, gamepad buttons that are still physically held are ignored until released, and OS key repeat is ignored, so refocusing the window never fires a press nobody made.
