# Cosmic Drift

A premium 2.5D sci-fi action-platformer for web, iOS, and Android. The product, engineering, and production source of truth is [`docs/MASTER_SPEC.md`](docs/MASTER_SPEC.md).

## Development

- Node.js 24 or 26 LTS (the exact local pin is in `.nvmrc`)
- npm (the lockfile is committed)

```sh
npm ci
npm run dev
npm run verify
npm run test:e2e
```

See [`AGENTS.md`](AGENTS.md), [`docs/PROGRESS.md`](docs/PROGRESS.md), and [`docs/HANDOFF.md`](docs/HANDOFF.md) before contributing. Work proceeds one approved milestone at a time.
