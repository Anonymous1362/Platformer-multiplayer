**Pipeline test build.** This only proves the Android app builds, installs, and opens. There is no gameplay yet: you will see a placeholder space screen with the screen size.

### Install on Android

1. Tap `cosmic-drift-0.0.1.apk` below to download it.
2. Open the downloaded file. If Android asks, allow your browser or Files app to "install unknown apps".
3. Tap **Install**, then **Open**. The game opens in landscape.

Future versions install over this one without uninstalling.
